1. echo : print text 

>> echo > text.tx

2. path name expansion (*)
we put * to declare the file inside the folder 


>>echo price * to run the command
price phone.txt tech.txt to run the command

similar name called: 

- asterisk 
- wildcard character or aka globbing patterns 


* = anything else 

Ex1: 

>> ls *.html 

>> cat blue*

Ex2 :

>> echo *.txt
phone.txt tech.txt


ex3: want to find the sentence or word that start with letter p 

>> echo p*

phone.txt

note this is cash sensitive: p is difference from P 

>> touch pho.txt phat.js cat.js
