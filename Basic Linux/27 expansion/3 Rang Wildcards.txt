[] = specify a range of characters to match (any much inside the rang) 

Ex: >> ls [A-F]*

Ex: 

>> echo app?.css
app1.css app2.css app3.css app4.css


>> echo app[123].css
app1.css app2.css app3.css


or 

>> echo app[1-3].css

app1.css app2.css app3.css

or 

>> echo app[2-4].css
app2.css app3.css app4.css


Ex: show the folder or file that start with capital letter 

[A-Z]*


>> echo [A-Z]*

Clearnup FilesExercise FilesExercise.zip PythonH Redirection Todos Udemy - The Linux Command Line Bootcamp Beginner To Power User 2025-1

or 

>> echo [A-N]*
Clearnup FilesExercise FilesExercise.zip
