Explain 

1- vibol : is the owner (file owner)
2- vibol : group owner 
3- drwxrwxr-x : this is 10 digit call file attribute : 

+ 1 digit : file type 
	- regular file (normal file that have extension) 
	d directory 
	c character special file (mostly connected to the hardware) 
	I symbolic link (Inline commands)
		Ex: echo "Today is $(date)"
	b block special file (most of them refer to the hardware file) 

+ digit from 2 to 4 : rwx (refer the owner permission) 

Ex:

drwxr-xr-x 2 braly braly 4096 Dec  8 15:12 Desktop

+ digit from : r-x (refer to the group owner)

+ the remain last 3 digit : refer to  (any one else or everyone)

ex: r-x
