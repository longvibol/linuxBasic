1. find the file that is the last modification time 

Ex: find file that modifiy 30 min ago 

>> find -mmin 30 (exact time ) 
>> find -mmin -30 (less than 30 mins)
>> find -mmin +30 (more than 30 mins)

Ex1: 

>> vibol@khcam:~/Desktop/Timing$ find -mmin -30
.
./10_mins_ago
./right_now


Ex2:

>> vibol@khcam:~/Desktop/Timing$ find -mmin +30
./two_days_ago
./last_week
./last_month
./MYFILE.txt
./three_days_ago
./30_mins_ago
